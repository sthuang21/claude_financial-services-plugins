# 台股買賣點判斷 Skill

## 核心理念
買賣點判斷採三維驗證：基本面確認價值、技術面找時機、籌碼面確認方向。
三維同向時訊號最強，僅單維符合時降低倉位或觀望。

## 評分系統（總分 10 分）

### 基本面（0–3 分）
| 條件 | 加分 |
|---|---|
| 近三季 EPS 年增率為正 | +1 |
| 月營收年增率連續兩個月回升 | +1 |
| 毛利率維持或擴張（非壓縮） | +0.5 |
| ROE > 15% | +0.5 |

### 技術面（0–4 分）

**買點技術條件：**
| 條件 | 加分 |
|---|---|
| 週KD 低檔交叉（K從30以下向上穿越D） | +1.5 |
| 日KD 低檔交叉（K從20以下向上穿越D） | +0.5 |
| 股價站上月線（20MA）且月線向上 | +1 |
| MACD 柱狀圖由負轉正 | +0.5 |
| 股價位於布林通道下緣附近反彈 | +0.5 |

**賣點技術條件（反向扣分）：**
| 條件 | 扣分 |
|---|---|
| 週KD 高檔交叉（K從80以上向下穿越D） | -1.5 |
| 日KD 高檔交叉（K從80以上向下穿越D） | -0.5 |
| 股價跌破月線（20MA）且月線向下 | -1 |
| MACD 柱狀圖由正轉負 | -0.5 |
| 乖離率超過 +15%（距月線過遠） | -0.5 |

### 籌碼面（0–3 分）

**買點籌碼條件：**
| 條件 | 加分 |
|---|---|
| 外資近 5 日累計買超 | +1 |
| 投信近 3 日買超 | +0.5 |
| 融資餘額減少但股價持平或上漲 | +0.5 |
| 大戶持股比例增加（股權分散表） | +1 |

**賣點籌碼條件（反向扣分）：**
| 條件 | 扣分 |
|---|---|
| 外資近 5 日累計賣超 | -1 |
| 投信近 3 日賣超 | -0.5 |
| 融資餘額快速增加（週增幅 > 5%） | -0.5 |
| 大戶持股比例減少 | -1 |

## 綜合評分對應建議

| 總分 | 建議 | 說明 |
|---|---|---|
| 8–10 分 | ✅ 強烈買進 | 三維同向，訊號極強 |
| 6–7 分 | 🟢 買進 | 多數條件符合，可進場 |
| 4–5 分 | 🟡 觀望 | 訊號混合，等待確認 |
| 2–3 分 | 🟠 偏空觀望 | 多數條件不利，避免進場 |
| 0–1 分 | 🔴 賣出 / 避開 | 三維同向偏空，出場或停損 |
| 負分 | ⛔ 強烈賣出 | 賣出訊號極強，立即出場 |

---

## 週期對應條件差異

### 短線（1–5 天）
- 技術面以日KD、成交量為主
- 籌碼面看當日及近 3 日法人動向
- 基本面：月營收年增率不衰退即可
- 停損設定：跌破進場日低點 3% 停損

### 波段（2–6 週）
- 技術面以週KD、月線為主
- 籌碼面看近 10–20 日法人累計動向
- 基本面：近三季 EPS 趨勢需為正
- 停損設定：跌破季線（60MA）停損

## 支撐壓力計算方式

### 支撐位（買點目標區）
1. 季線（60MA）
2. 前波低點
3. 布林通道下緣
4. 整數關卡（心理支撐）

### 壓力位（賣點目標區）
1. 前波高點（52週高點）
2. 布林通道上緣
3. 月線乖離 +10–15%
4. 整數關卡（心理壓力）

## 重要聲明
買賣點判斷基於歷史數據統計，不代表未來必然走勢。
所有建議僅供參考，不構成投資建議，投資人需自行判斷風險。
